# Alex Morgan's Portfolio

A responsive, beginner-friendly personal portfolio made with plain HTML, CSS, and JavaScript. It has no build step, dependencies, paid services, or backend.

## Run locally

1. Download or clone this project.
2. Open `index.html` in a modern web browser.

You can also use the Live Server extension in Visual Studio Code and choose **Open with Live Server** while `index.html` is open. The website works without it.

## Make it yours

1. In `index.html`, replace **Alex Morgan** with your name, then update the introduction, location, About section, skills, and project descriptions.
2. Replace `hello@example.com` with your email address in the contact link and visible text.
3. Update the three sample projects with your own project names, dates, descriptions, and skills. The artwork is drawn with CSS, so no image files are required.
4. In `style.css`, adjust the color variables near the top to personalize the palette.
5. Change the page title and description in the `<head>` of `index.html` to match your portfolio.

The profile illustration is a CSS placeholder. Replace it with a photo or your own artwork if you prefer. The Google Fonts import is optional; if you remove it, the built-in Georgia and system-font fallbacks keep the site readable.
